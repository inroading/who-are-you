先修这几项

    • 时区与 IP
      • 系统时区改成 IP 所在地
      • Windows：设置 → 时间和语言
      • macOS：系统设置 → 通用 → 日期与时间
    • 语言与 IP
      • 浏览器语言设置里，把 IP 所在国的语言排第一
      • 不需要装成当地人，可以不管
    • 系统语言与 IP
      • 系统装了别的语言包，字体和语音会把它暴露出来
      • 换一台没装这些语言的系统或虚拟机
      • 或者选和系统语言一致的地区节点
    • DNS 泄露DNS 测试
      • Clash / Mihomo：DNS 开 fake-ip，或开 TUN 模式
      • V2Ray / Xray：DNS 也走代理
      • 浏览器：开启「安全 DNS」
    • 分流出口照妖镜
      • 不想被看出：切到全局模式
      • 有意让国内直连，可以不管
    • WebRTC 泄露出口照妖镜
      • 代理客户端开 TUN 模式
      • 或在浏览器里限制 WebRTC（Chrome 装 WebRTC Network Limiter）
    • 延迟与连接
      • 代理难免多出这一段延迟，网站能据此判断
      • 选离你更近、延迟更低的节点，差距会小一些
      • 住宅或手机网络的出口比机房 IP 更不容易被怀疑
    • 机房 IPIP 质量测试
      • 换成家宽或手机网络的出口
      • 流媒体、AI、支付网站常拦机房 IP
    • UA 与真实系统
      • 别只改 UA，显卡会露馅
      • 要多个身份，用指纹浏览器
    • 环境被篡改
      • 改 UA、语言、时区的插件只改了 JS 读到的那一份，请求头和底层函数还是原样
      • 要伪装就在系统层面改：系统语言、时区
      • 用指纹浏览器的话，确认它的各项设置前后一致
    • 指纹浏览器痕迹
      • 指纹浏览器里，用户代理的版本选成和内核版本一致
      • 别只改页面里的 navigator：Worker 读到的也要一样（用内核级修改，不用注入脚本）
      • 系统、平台、显卡厂商这几项要选同一套，别混搭
    • 指纹可追踪
      • 换 Brave（自动打乱指纹）
      • 或 Firefox 开启 resistFingerprinting
      • 或用 Tor 浏览器
    • 自动化痕迹
      • 关掉 Selenium、Puppeteer 等自动化工具后刷新
    连接协议
    • HTTP/3
      • 让代理转发 UDP（Clash / Mihomo：TUN 模式，udp: true）
      • 防火墙放行 UDP 443
      • 确认浏览器没关掉 QUIC
    • ECH
      • 浏览器开「安全 DNS」（DNS over HTTPS）
      • 代理：关掉 fake-ip，或让它的 DNS 返回 HTTPS 记录
      • 用支持 ECH 的浏览器：Chrome、Edge、Firefox
    • 后量子加密
      • 升级浏览器
      • 关掉杀毒软件的 HTTPS 扫描，或问问公司代理是否解密流量
    • WARP
      • Cloudflare WARP：在 1.1.1.1 应用里开关

      帮助

      什么是 DNS 泄露？

      浏览器连接网站之前，要先由 DNS 解析器把域名换成地址。如果这一步没走 VPN 或代理，查询就发给了你本地运营商的解析器：运营商能看到你访问的每个网站；网站把解析器和你的 IP 一对比，也能看出你在用 VPN，以及你实际在哪。

      这个检测怎么找到我的解析器？

      页面会查询 edns.ip-api.com 下一个随机的、从没人查过的域名，所以没有缓存能直接回答：你的解析器只能去问 ip-api 的权威服务器，它会报告解析器的地址和运营商；如果解析器带上了你的客户端子网（ECS），也会一起报告。检测再把解析器所在国家和你 IP 的国家对比。

      DNS 泄露怎么修？

      Clash / Mihomo：开启 DNS，并把 enhanced-mode 设为 fake-ip，或者开 TUN 模式让所有查询都经过它。V2Ray / Xray 客户端：让 DNS 也走代理（或者设置一个走代理的 DoH 服务器）。浏览器里打开「安全 DNS」（DoH）也能让查询避开运营商。改完再测一次。

      解析器显示是 Cloudflare 或 Google，但在另一个城市，算泄露吗？

      一般不算。1.1.1.1、8.8.8.8 这类公共 DNS 会从离请求最近的数据中心回答，所以城市可能和 VPN 出口不一样。真正会暴露你的，是本地运营商的解析器，或者 IP 在国外、解析器却在国内。
