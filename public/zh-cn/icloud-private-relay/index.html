      我关心

      先改这几项

      • 时区和 IP
        • 把系统时区改成 IP 所在地的
        • Windows：设置 → 时间和语言
        • macOS：系统设置 → 通用 → 日期与时间
      • 语言和 IP
        • 在浏览器的语言设置里，把 IP 所在国的语言排到第一
        • 不需要装成当地人的话，可以不管
      • 系统语言和 IP
        • 系统装了别的语言包，字体和语音会把它暴露出来
        • 换一个没装这些语言的系统或虚拟机
        • 或者选一个和系统语言一致的地区
      • DNS 泄露DNS 测试
        • Clash / Mihomo：DNS 用 fake-ip，或者开 TUN 模式
        • V2Ray / Xray：让 DNS 也走代理
        • 浏览器：打开「安全 DNS」
      • 分流出口照妖镜
        • 不想被看出来：切到全局模式
        • 国内网站是你有意让它直连的，可以不管
      • WebRTC 泄露出口照妖镜
        • 代理客户端打开 TUN 模式
        • 或者在浏览器里限制 WebRTC（Chrome 装 WebRTC Network Limiter）
      • 往返延迟
        • 代理一定会多出这一段路，网站量得出来
        • 选离你更近、延迟更低的节点，差距会小一些
        • 家宽或手机网络的出口，比机房 IP 更不容易被怀疑
      • 连接指纹
        • TCP 包由系统发出，浏览器和指纹浏览器都改不了，换 UA 骗不过这一项
        • 全局 VPN 或代理会让 TCP 变成服务器的系统，这本身就说明你在用代理
        • 抓包软件、公司网关、杀毒软件的 HTTPS 扫描会改掉 TLS 和 HTTP/2 指纹，可以关掉试试
      • 机房 IPIP 质量测试
        • 换成家宽或手机网络的出口
        • 流媒体、AI 和支付网站常常拦机房 IP
      • UA 和真实系统
        • 别只改 UA，显卡会露馅
        • 需要多个身份，就用指纹浏览器
      • 环境被篡改
        • 改 UA、语言、时区的插件只改了 JS 读到的那一份，请求头和底层函数还是原样
        • 要伪装，就在系统里改：系统语言和时区
        • 用指纹浏览器的话，确认它的各项设置互相一致
      • 指纹浏览器痕迹
        • 在指纹浏览器里，把 UA 版本选成和内核版本一致
        • 别只改页面里的 navigator，Worker 读到的也要一样（用内核级修改，别用注入脚本）
        • 系统、平台、显卡厂商选成同一套，别混搭
      • 指纹追踪
        • 换用 Brave（会自动打乱指纹）
        • 或者在 Firefox 里打开 resistFingerprinting
        • 或者用 Tor 浏览器
      • 自动化痕迹
        • 关掉 Selenium、Puppeteer 等自动化工具，再刷新页面
      连接协议
      • HTTP/3
        • 让代理转发 UDP（Clash / Mihomo：TUN 模式，udp: true）
        • 防火墙放行 UDP 443
        • 确认浏览器没关掉 QUIC
      • ECH
        • 浏览器打开「安全 DNS」（DNS over HTTPS）
        • 代理：关掉 fake-ip，或者让它的 DNS 返回 HTTPS 记录
        • 换用支持 ECH 的浏览器：Chrome、Edge、Firefox
      • 后量子加密
        • 更新浏览器
        • 关掉杀毒软件的 HTTPS 扫描，或者问问公司代理会不会解密流量
      • WARP
        • Cloudflare WARP：在 1.1.1.1 App 里开关

        常见问题

        网站看得出我在用专用代理吗？

        看得出。苹果公开了它所有出口的地址列表，这个页面就是拿你的地址去对照的。网站看到的是中继出口，不是你自己的地址，但通常还能看到你附近的城市或地区：苹果有意保留这一点，好让本地内容照常显示。

        专用代理是 VPN 吗？

        不是。它只管 Safari 和 App 里没加密的流量，不是所有 App；不能选别的国家；它对网站隐藏你的地址，对网络运营商隐藏你访问了什么。在网站眼里，它像一个隐私中继，而不像一个人在国外。

        为什么 WebRTC 显示的是另一个中继地址？

        每条连接都有自己的出口，所以页面和 WebRTC 可能从不同的中继地址出去。两个都是中继出口，不算泄露；只有旁边出现了你的真实地址，检测才会报警。
