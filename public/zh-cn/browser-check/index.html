我关心

先修这几项

    • 时区与 IP
      • 系统时区改成 IP 所在地
      • Windows：设置 → 时间和语言
      • macOS：系统设置 → 通用 → 日期与时间
    • 语言与 IP
      • 浏览器语言设置里，把 IP 所在国的语言排第一
      • 不需要装成当地人，可以不管
    • 系统语言与 IP
      • 系统装了别的语言包，字体和语音会把它暴露出来
      • 换一台没装这些语言的系统或虚拟机
      • 或者选和系统语言一致的地区节点
    • DNS 泄露DNS 测试
      • Clash / Mihomo：DNS 开 fake-ip，或开 TUN 模式
      • V2Ray / Xray：DNS 也走代理
      • 浏览器：开启「安全 DNS」
    • 分流出口照妖镜
      • 不想被看出：切到全局模式
      • 有意让国内直连，可以不管
    • WebRTC 泄露出口照妖镜
      • 代理客户端开 TUN 模式
      • 或在浏览器里限制 WebRTC（Chrome 装 WebRTC Network Limiter）
    • 延迟与连接
      • 代理难免多出这一段延迟，网站能据此判断
      • 选离你更近、延迟更低的节点，差距会小一些
      • 住宅或手机网络的出口比机房 IP 更不容易被怀疑
    • 机房 IPIP 质量测试
      • 换成家宽或手机网络的出口
      • 流媒体、AI、支付网站常拦机房 IP
    • UA 与真实系统
      • 别只改 UA，显卡会露馅
      • 要多个身份，用指纹浏览器
    • 环境被篡改
      • 改 UA、语言、时区的插件只改了 JS 读到的那一份，请求头和底层函数还是原样
      • 要伪装就在系统层面改：系统语言、时区
      • 用指纹浏览器的话，确认它的各项设置前后一致
    • 指纹浏览器痕迹
      • 指纹浏览器里，用户代理的版本选成和内核版本一致
      • 别只改页面里的 navigator：Worker 读到的也要一样（用内核级修改，不用注入脚本）
      • 系统、平台、显卡厂商这几项要选同一套，别混搭
    • 指纹可追踪
      • 换 Brave（自动打乱指纹）
      • 或 Firefox 开启 resistFingerprinting
      • 或用 Tor 浏览器
    • 自动化痕迹
      • 关掉 Selenium、Puppeteer 等自动化工具后刷新
    连接协议
    • HTTP/3
      • 让代理转发 UDP（Clash / Mihomo：TUN 模式，udp: true）
      • 防火墙放行 UDP 443
      • 确认浏览器没关掉 QUIC
    • ECH
      • 浏览器开「安全 DNS」（DNS over HTTPS）
      • 代理：关掉 fake-ip，或让它的 DNS 返回 HTTPS 记录
      • 用支持 ECH 的浏览器：Chrome、Edge、Firefox
    • 后量子加密
      • 升级浏览器
      • 关掉杀毒软件的 HTTPS 扫描，或问问公司代理是否解密流量
    • WARP
      • Cloudflare WARP：在 1.1.1.1 应用里开关

      帮助

      这个检测看哪些地方？

      网站读的属性（UA、平台、语言、屏幕）是不是被重新定义过，指纹用到的画图和音频函数有没有被替换，JS 引擎和 UA 对不对得上，请求头里的语言和 JS 里的是否一致，Date 和 Intl 给出的时区是否相同。页面上其他检测项也都计入评分。

      为什么改 UA 的插件会被识破？

      它们只改了 JS 读到的那一份，浏览器发出的请求头、底层引擎、被它们包起来的函数都还是原样。每一处对不上，网站都能比出来。想伪装成在别处，要在系统层面改：系统语言和时区。

      会保存什么吗？

      不存关于你本人的东西。检测都在你的浏览器里进行，服务器只回答它从这次请求里本来就能看到的东西。检测完，页面会给匿名计数器加一（你的各项读数、每项检查的结果），不存 IP，也没有单次访问的记录；页面上的「不参与统计」可以关掉。
