說明

什麼是 DNS 洩漏？

瀏覽器連上網站之前，要先由 DNS 解析器把網域換成位址。如果這一步沒走 VPN 或代理，查詢就送到你本地電信業者的解析器：業者看得到你造訪的每個網站；網站把解析器和你的 IP 一比對，也看得出你在用 VPN，以及你實際在哪。

這個檢測怎麼找到我的解析器？

頁面會查詢 edns.ip-api.com 底下一個隨機、從沒人查過的網域，所以沒有快取能直接回答：你的解析器只能去問 ip-api 的權威伺服器，它會回報解析器的位址和業者；如果解析器帶上了你的用戶端子網（ECS），也會一起回報。檢測再把解析器所在國家和你 IP 的國家比對。

DNS 洩漏怎麼修？

Clash / Mihomo：開啟 DNS，並把 enhanced-mode 設為 fake-ip，或開 TUN 模式讓所有查詢都經過它。V2Ray / Xray 用戶端：讓 DNS 也走代理（或設定一個走代理的 DoH 伺服器）。瀏覽器裡開啟「安全 DNS」（DoH）也能讓查詢避開業者。改完再測一次。

解析器是 Cloudflare 或 Google，但在另一個城市，算洩漏嗎？

通常不算。1.1.1.1、8.8.8.8 這類公共 DNS 會從離請求最近的資料中心回答，所以城市可能和 VPN 出口不一樣。真正會暴露你的，是本地電信業者的解析器，或者 IP 在國外、解析器卻在本國。
