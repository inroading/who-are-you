先修這幾項

    • 時區與 IP
      • 系統時區改成 IP 所在地
      • Windows：設定 → 時間與語言
      • macOS：系統設定 → 一般 → 日期與時間
    • 語言與 IP
      • 瀏覽器語言設定裡，把 IP 所在國的語言排第一
      • 不需要裝成當地人，可以不管
    • 系統語言與 IP
      • 系統裝了別的語言套件，字型和語音會把它暴露出來
      • 換一台沒裝這些語言的系統或虛擬機
      • 或者選和系統語言一致的地區節點
    • DNS 洩漏DNS 測試
      • Clash / Mihomo：DNS 開 fake-ip，或開 TUN 模式
      • V2Ray / Xray：DNS 也走代理
      • 瀏覽器：開啟「安全 DNS」
    • 分流出口照妖鏡
      • 不想被看出：切到全域模式
      • 有意讓本地網站直連，可以不管
    • WebRTC 洩漏出口照妖鏡
      • 代理用戶端開 TUN 模式
      • 或在瀏覽器裡限制 WebRTC（Chrome 安裝 WebRTC Network Limiter）
    • 延遲與連線
      • 代理難免多出這一段延遲，網站能據此判斷
      • 選離你更近、延遲更低的節點，差距會小一些
      • 住宅或行動網路的出口比機房 IP 更不容易被懷疑
    • 機房 IPIP 品質測試
      • 換成家用寬頻或行動網路的出口
      • 串流、AI、支付網站常擋機房 IP
    • UA 與真實系統
      • 別只改 UA，顯示卡會露餡
      • 要多個身分，用指紋瀏覽器
    • 環境被竄改
      • 改 UA、語言、時區的擴充功能只改了 JS 讀到的那一份，請求標頭和底層函式還是原樣
      • 要偽裝就在系統層面改：系統語言、時區
      • 用指紋瀏覽器的話，確認它的各項設定前後一致
    • 指紋瀏覽器痕跡
      • 在指紋瀏覽器裡，把使用者代理的版本選成和核心版本一致
      • 別只改頁面裡的 navigator：Worker 讀到的也要一樣（用核心層級的修改，不用注入腳本）
      • 系統、平台、顯示卡廠商這幾項要選同一套，別混搭
    • 指紋可追蹤
      • 換 Brave（自動打亂指紋）
      • 或 Firefox 開啟 resistFingerprinting
      • 或用 Tor 瀏覽器
    • 自動化痕跡
      • 關掉 Selenium、Puppeteer 等自動化工具後重新整理
    連線協定
    • HTTP/3
      • 讓代理轉發 UDP（Clash / Mihomo：TUN 模式，udp: true）
      • 防火牆放行 UDP 443
      • 確認瀏覽器沒關掉 QUIC
    • ECH
      • 瀏覽器開「安全 DNS」（DNS over HTTPS）
      • 代理：關掉 fake-ip，或讓它的 DNS 回傳 HTTPS 記錄
      • 用支援 ECH 的瀏覽器：Chrome、Edge、Firefox
    • 後量子加密
      • 更新瀏覽器
      • 關掉防毒軟體的 HTTPS 掃描，或問問公司代理是否解密流量
    • WARP
      • Cloudflare WARP：在 1.1.1.1 應用程式裡開關

      說明

      為什麼沒用上 HTTP/3？

      HTTP/3 走 UDP 443 連接埠。瀏覽器要先透過 TCP 收到網站的第一次回應，才知道它支援 HTTP/3，所以第一次造訪可能還沒切換；但如果 UDP 哪裡都出不去，就是網路或代理把它擋了，或者根本不轉送 UDP。很多代理設定只轉 TCP。

      ECH 是什麼，為什麼沒開？

      Encrypted Client Hello 會加密網站名稱。否則 TLS 會明文傳送它，路上誰都看得到。瀏覽器得從 DNS 的 HTTPS 紀錄裡拿到網站的金鑰：Firefox 只在用自己的 DNS over HTTPS 時讀取；Chrome 需要能回傳 HTTPS 紀錄的解析器；Safari 目前還不用 ECH。

      金鑰交換是傳統的，代表什麼？

      Chrome 124+、Firefox 132+ 和 Safari 26 預設都會提供 X25519MLKEM768。新瀏覽器最後卻用了普通的 X25519，代表中間有東西自己建立了 TLS 連線：防毒軟體、公司代理，或會解開 TLS 的代理用戶端。舊瀏覽器則只是版本太舊。
