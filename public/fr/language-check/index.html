      Mon objectif

      À corriger d’abord

      • Fuseau et IP
        • Réglez le fuseau du système sur celui de l’IP
        • Windows : Paramètres → Heure et langue
        • macOS : Réglages Système → Général → Date et heure
      • Langue et IP
        • Mettez la langue du pays de l’IP en premier dans le navigateur
        • Vous ne cherchez pas à passer pour un habitant ? Laissez tel quel
      • Langue du système et IP
        • Le système a un autre pack de langue installé, et ses polices et voix le trahissent
        • Utilisez un système ou une machine virtuelle sans ces langues
        • Ou choisissez une région qui correspond à la langue du système
      • Fuite DNSTest DNS
        • Clash / Mihomo : DNS en fake-ip, ou mode TUN
        • V2Ray / Xray : faites aussi passer le DNS par le proxy
        • Navigateur : activez le DNS sécurisé
      • Routage séparéLoupe IP
        • Pour ne pas être repéré : passez en mode global
        • Les sites locaux passent en direct exprès ? Laissez tel quel
      • Fuite WebRTCLoupe IP
        • Client proxy : activez le mode TUN
        • Ou limitez WebRTC dans le navigateur (Chrome : WebRTC Network Limiter)
      • Aller-retour
        • Un proxy ajoute toujours ce détour, et les sites peuvent le mesurer
        • Un serveur plus proche, avec moins de latence, réduit l’écart
        • Une sortie résidentielle ou mobile éveille moins les soupçons qu’une IP de datacenter
      • Empreinte de connexion
        • Votre système écrit les paquets TCP : aucun navigateur ni navigateur anti-détection ne les change, et changer d'user agent ne trompe pas ce test
        • Un VPN ou un proxy en tunnel complet rend le TCP celui de son serveur, ce qui trahit déjà un proxy
        • Les outils de capture, les passerelles d'entreprise et l'analyse HTTPS des antivirus changent les empreintes TLS et HTTP/2 : essayez de les couper
      • IP de datacenterTest qualité IP
        • Prenez plutôt une sortie résidentielle ou mobile
        • Les sites de streaming, d’IA et de paiement bloquent souvent les datacenters
      • User agent et système
        • Ne changez pas seulement le user agent : la carte graphique vous trahit
        • Besoin de plusieurs identités ? Prenez un navigateur anti-détection
      • Environnement modifié
        • Les extensions qui changent le user agent, la langue ou le fuseau ne changent que ce que lit JavaScript ; les en-têtes et les fonctions sous-jacentes restent les mêmes
        • Pour paraître ailleurs, changez le système lui-même : sa langue et son fuseau
        • Avec un navigateur anti-détection, vérifiez que ses réglages concordent entre eux
      • Traces d’un navigateur anti-détection
        • Dans le navigateur anti-détection, choisissez une version de user agent qui correspond à son moteur
        • Ne modifiez pas seulement le navigator de la page : un Worker doit lire la même chose (modification dans le moteur, pas un script injecté)
        • Choisissez système, plateforme et fabricant graphique comme un tout cohérent, sans les mélanger
      • Empreinte traçable
        • Utilisez Brave (il brouille l’empreinte)
        • Ou Firefox avec resistFingerprinting
        • Ou Tor Browser
      • Automatisation
        • Fermez Selenium, Puppeteer ou tout autre outil d’automatisation, puis rechargez
      Connexion
      • HTTP/3
        • Faites transporter l’UDP par le proxy (Clash / Mihomo : mode TUN, udp: true)
        • Autorisez l’UDP 443 dans le pare-feu
        • Vérifiez que QUIC n’est pas désactivé dans le navigateur
      • ECH
        • Activez le DNS sécurisé (DNS over HTTPS) dans le navigateur
        • Proxy : désactivez le fake-ip, ou faites renvoyer les enregistrements HTTPS par son DNS
        • Utilisez un navigateur compatible ECH : Chrome, Edge, Firefox
      • Post-quantique
        • Mettez le navigateur à jour
        • Désactivez l’analyse HTTPS de l’antivirus, ou demandez si le proxy de l’entreprise déchiffre le trafic
      • WARP
        • Cloudflare WARP : activez-le ou coupez-le dans l’app 1.1.1.1

        Aide

        D’où les sites tirent-ils ma langue ?

        De l’en-tête Accept-Language envoyé avec chaque requête, de navigator.languages dans JavaScript, et indirectement des paramètres régionaux, de la disposition du clavier, des voix de synthèse et des polices installées sur votre système.

        Comment la changer ?

        Dans les réglages de langue du navigateur : placez la langue voulue en premier. Si vous ne changez qu’un seul endroit, par exemple avec une extension qui modifie navigator.languages, l’en-tête reste inchangé et les deux ne concordent plus.

        Pourquoi l’anglais n’est-il qu’une « info » ?

        L’anglais est utilisé partout : il ne dit presque rien de l’endroit où vous êtes. Les autres langues renvoient à un pays, et un décalage avec l’IP devient un indice.
