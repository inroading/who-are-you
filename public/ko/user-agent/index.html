먼저 고칠 것

    • 시간대와 IP
      • 시스템 시간대를 IP 위치로
      • Windows: 설정 → 시간 및 언어
      • macOS: 시스템 설정 → 일반 → 날짜 및 시간
    • 언어와 IP
      • 브라우저 언어 설정에서 IP 국가의 언어를 맨 위로
      • 현지인처럼 보일 필요 없으면 그대로
    • 시스템 언어와 IP
      • 시스템에 다른 언어 팩이 설치돼 있고, 글꼴과 음성에서 드러나요
      • 그 언어가 없는 시스템이나 가상 머신을 쓰기
      • 아니면 시스템 언어와 맞는 지역 서버를 고르기
    • DNS 유출DNS 테스트
      • Clash / Mihomo: DNS를 fake-ip로, 또는 TUN 모드
      • V2Ray / Xray: DNS도 프록시로
      • 브라우저: 보안 DNS 켜기
    • 분할 라우팅출구 IP 돋보기
      • 숨기려면: 글로벌 모드로
      • 국내 사이트 직결이 의도라면 그대로
    • WebRTC 유출출구 IP 돋보기
      • 프록시 클라이언트에서 TUN 모드 켜기
      • 또는 브라우저에서 WebRTC 제한(Chrome: WebRTC Network Limiter)
    • 왕복 지연
      • 프록시를 거치면 이 구간만큼 지연이 늘고, 사이트는 그걸 잴 수 있어요
      • 가깝고 지연이 낮은 서버를 고르면 차이가 줄어요
      • 가정용·모바일 출구가 데이터센터 IP보다 덜 의심받아요
    • 데이터 센터 IPIP 품질 테스트
      • 가정용이나 모바일 출구로 바꾸기
      • 스트리밍, AI, 결제 사이트는 데이터 센터를 자주 막음
    • UA와 실제 시스템
      • UA만 바꾸지 말기: 그래픽 카드로 들킴
      • 여러 신원이 필요하면 안티디텍트 브라우저
    • 환경 변조
      • UA·언어·시간대를 바꾸는 확장 프로그램은 JS가 읽는 값만 바꾸고, 요청 헤더와 아래 함수는 그대로예요
      • 위장하려면 시스템에서 바꾸기: 언어와 시간대
      • 안티디텍트 브라우저라면 설정끼리 서로 맞는지 확인
    • 안티디텍트 브라우저 흔적
      • 안티디텍트 브라우저에서 사용자 에이전트 버전을 엔진 버전과 맞추세요
      • 페이지의 navigator만 바꾸지 마세요: Worker에서도 같은 값이어야 해요(스크립트 주입이 아닌 커널 수준 변경)
      • 시스템, 플랫폼, 그래픽 벤더는 한 세트로 고르고 섞지 마세요
    • 추적 가능한 지문
      • Brave 쓰기(지문 자동 뒤섞기)
      • 또는 Firefox에서 resistFingerprinting
      • 또는 Tor 브라우저
    • 자동화 흔적
      • Selenium, Puppeteer 같은 자동화를 끄고 새로고침
    연결 프로토콜
    • HTTP/3
      • 프록시가 UDP를 전달하게 하기(Clash / Mihomo: TUN 모드, udp: true)
      • 방화벽에서 UDP 443 허용
      • 브라우저에서 QUIC이 꺼져 있지 않은지 확인
    • ECH
      • 브라우저에서 보안 DNS(DNS over HTTPS) 켜기
      • 프록시: fake-ip를 끄거나 DNS가 HTTPS 레코드를 돌려주게 하기
      • ECH를 지원하는 브라우저 사용: Chrome, Edge, Firefox
    • 양자 내성 암호
      • 브라우저 업데이트
      • 백신의 HTTPS 검사를 끄거나, 회사 프록시가 트래픽을 복호화하는지 확인
    • WARP
      • Cloudflare WARP: 1.1.1.1 앱에서 켜고 끄기

      도움말

      사용자 에이전트란?

      모든 요청에 붙는 한 줄의 텍스트로 브라우저, 버전, 시스템을 알려요. Chromium 계열은 같은 정보를 구조화한 클라이언트 힌트도 보냅니다.

      Windows 11인데 왜 Windows 10으로 나오나요?

      개인정보 보호를 위해 브라우저가 UA를 Windows 10(macOS는 10.15)으로 고정했어요. 실제 버전은 클라이언트 힌트에서 나오며, 이 페이지는 그걸 보여 줍니다.

      위장할 수 있나요?

      문자열은 바꿀 수 있지만 JS 엔진, 그래픽 카드, 클라이언트 힌트가 다른 말을 하는 경우가 많아요. 이 페이지의 검사가 어디가 안 맞는지 보여 줍니다.
