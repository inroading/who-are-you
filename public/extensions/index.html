Sniffing…

 

  • Time zone vs IP
    • Set the system time zone to the IP's
    • Windows: Settings → Time & language
    • macOS: System Settings → General → Date & Time
  • Language vs IP
    • Put the IP country's language first in the browser
    • Not passing as a local? Leave it
  • System language vs IP
    • The system has another language pack installed, and its fonts and voices show it
    • Use a system or virtual machine without those languages
    • Or pick a region that matches the system's language
  • DNS leakDNS Test
    • Clash / Mihomo: DNS with fake-ip, or TUN mode
    • V2Ray / Xray: send DNS through the proxy too
    • Browser: turn on Secure DNS
  • Split routingEgressLens
    • To hide it: switch to global mode
    • Local sites going direct on purpose? Leave it
  • WebRTC leakEgressLens
    • Proxy client: turn on TUN mode
    • Or limit WebRTC in the browser (Chrome: WebRTC Network Limiter)
  • Round trip
    • A proxy always adds this leg, and sites can measure it
    • A server closer to you, with less latency, narrows the gap
    • Residential or mobile exits raise fewer eyebrows than data center IPs
  • Data center IPIP Quality Test
    • Use a home or mobile exit instead
    • Streaming, AI and payment sites often block data centers
  • User agent vs system
    • Don't change the user agent alone: the graphics card gives it away
    • Need several identities? Use an anti-detect browser
  • Tampered environment
    • Extensions that change the user agent, language or time zone only change what JavaScript reads; the request headers and the functions underneath stay as they were
    • To pass for elsewhere, change the system itself: its language and time zone
    • With an anti-detect browser, make sure its settings agree with each other
  • Trackable fingerprint
    • Use Brave (scrambles the fingerprint)
    • Or Firefox with resistFingerprinting
    • Or Tor Browser
  • Automation
    • Close Selenium, Puppeteer or other automation, then reload
Connection
  • HTTP/3
    • Let the proxy carry UDP (Clash / Mihomo: TUN mode, udp: true)
    • Allow UDP 443 on the firewall
    • Check QUIC isn't turned off in the browser
  • ECH
    • Turn on secure DNS (DNS over HTTPS) in the browser
    • Proxy: turn off fake-ip, or have its DNS return HTTPS records
    • Use a browser that supports ECH: Chrome, Edge, Firefox
  • Post-quantum
    • Update the browser
    • Turn off HTTPS scanning in your antivirus, or ask whether the company proxy decrypts traffic
  • WARP
    • Cloudflare WARP: switch it in the 1.1.1.1 app

    Help

    How can a site see my extensions?

    It can't list them, but it can see what they leave behind: objects like window.ethereum, attributes on the page, elements they insert, scripts they add. Some extensions leave nothing and stay invisible.

    Why does it matter?

    Extensions narrow you down: a crypto wallet, developer tools or a particular translator says something about who you are, and adds to your fingerprint.

    What does the tamper check have to do with it?

    Extensions that change your user agent, language or time zone, or wrap the drawing functions fingerprints use, rewrite what sites read. That's what the check in front looks for.
